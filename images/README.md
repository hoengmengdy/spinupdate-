# Product images

Replace the eight included sample illustrations with your own product images:

- `product1.png`
- `product2.png`
- `product3.png`
- `product4.png`
- `product5.png`
- `product6.png`
- `product7.png`
- `product8.png`

Use transparent PNGs, ideally with little empty padding around the package. Keep
the entire product visible and upright, with its top at the top of the image.
Any image dimensions work: the wheel automatically contains each image without
stretching or cropping, then rotates it to face outward.

Edit the `products` array in `index.html` to set the real product names. Names
appear in the result popup, never as labels on the wheel. Use an empty name to
hide the popup name. The included PNGs are generic placeholder illustrations,
not photographs of actual prizes.
